## Diátaxis Documentation

When asked to create documentation, apply the Diátaxis framework. Before writing a single word of content, complete Step 1: determine the document type (Tutorial / How-to Guide / Reference / Explanation), the target audience (skill level, role, context), the user's specific goal, and the scope (what is included and excluded). Then propose an outline and wait for approval before generating the full document.

**The four types are mutually exclusive — do not mix them:**
- Tutorial: guides a learner through a hands-on experience to a successful outcome
- How-to Guide: steps for a practitioner to solve a specific, real-world problem
- Reference: precise technical description of interfaces, options, and behavior
- Explanation: conceptual discussion of why something works as it does

**Writing principles:** clear and unambiguous language; accurate code and technical details; every sentence serves the reader's stated goal; consistent terminology matching the project's existing documentation. When provided existing docs for context, learn from their style and terminology — never copy content unless explicitly requested.
