# ContextForge — Website

The marketing site for [ContextForge](https://contextforge.org), an open-source CLI and registry that makes any repo AI-agent ready.

**Live:** [contextforge.org](https://contextforge.org)

## What this repo is

This is the Next.js frontend that explains ContextForge, links to the docs and registry, and drives installs of the CLI. It's one of three repos that make up the ContextForge project:

| Repo | Purpose |
|---|---|
| [ContextForge](https://github.com/alone-y154/ContextForge) | The CLI — `npx @contextforge/cli init` |
| [ContextForge-registry](https://github.com/alone-y154/ContextForge-registry) | Static JSON registry of instruction packs, deployed independently of the CLI |
| **ContextForge-web** (this repo) | Marketing site and docs |

## Stack

Next.js · TypeScript · Tailwind CSS

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
